# AI相册（PhotoMind）

在自己手机上搜自己相册里的东西。输“身份证”就能从几万张照片里把它挑出来，也能直接对着麦克风说。证件类照片全程不离开设备。

## 它能做什么

- 文字搜索：身份证、护照、合同、发票、户口本、出生证明、疫苗本、银行卡……靠本机 OCR 读到证件上实际印的字，而不是“看起来像什么”
- 号码搜索：输“尾号 1234”这种片段也能找到，身份证号过 GB 11643 校验才入库，详情页只显示前 6 后 4
- 时间搜索：“去年”“上个月”“2024 年 3 月”直接翻译成日期区间
- 口语搜索：“身份证”会自动扩展成“居民身份证 / 公民身份号码 / 签发机关”等证件版面用词
- 语音搜索：系统自带的设备端识别，不经过任何第三方服务
- 找到之后：看大图、看识别出的原文与命中理由、分享、尝试在系统相册里定位它

## 它不做什么

- 不上传照片。工程里没有 URLSession，也没有任何网络调用（设备端语音不可用时才会降级到系统在线识别，界面上会写清楚）
- 不写相册。只申请读取权限，不删除、不修改、不自动建相簿
- 不用百炼、不用任何云端大模型

## 技术选择

PhotoKit + Vision（OCR + 场景分类）+ Speech（设备端）+ SwiftUI，零第三方依赖，无数据库。

中文检索不成词：用“相邻两字 bigram + 4096 位布隆签名”做召回，再加一层版面关键词加权打分。一万张照片常驻内存约 5 MB，一次全库打分十几毫秒。

工程用 XcodeGen 描述（`project.yml`），仓库里不存 `.xcodeproj`，避免合并冲突，也让云端能一键生成。

## 怎么装到 iPhone（无 Mac）

1. 仓库 Actions 跑完后，在最新一次运行底部下载 `PhotoMind-unsigned-ipa`
2. 电脑上装 SideStore（或 AltStore、爱思助手），用你自己的免费 Apple ID 登录
3. 把 IPA 导入 SideStore 安装到手机；首次打开去 设置 > 通用 > VPN与设备管理 里信任该开发者
4. 注意：免费 Apple ID 签发的包只有 7 天有效期，到期后电脑不离开手机 WiFi 会自动续签（SideStore 需要电脑和手机保持同一网络），这是苹果的限制，与本工程无关

## 自己重新打包

推送到 main 分支会自动触发构建。如果你还没把 `.github/workflows/ios.yml` 放进仓库，仓库里备了一份现成的：`Support/ios-workflow.yml`，内容全部复制粘贴到新文件 `.github/workflows/ios.yml` 提交即可（这一步需要你在 GitHub 网页上手动完成，助手无权代写工作流文件）。

## 当前状态（诚实说明）

- 代码已完成，但**没有经过任何编译器或真机验证**：开发环境是一台 Windows 电脑，没有 Xcode，Swift 语法只能靠人工逐文件把关。首次云端构建很可能需要根据日志修几处
- Vision 中文 OCR 对倾斜/反光证件的效果、以及分类阈值是否合适，必须用你自己的真实照片跑一轮才能调——遇到搜不到时，先看详情页的“本机读到的文字”那一段，能直接判断是 OCR 没读出来还是词没命中
- 跳系统相册某一张用的是非官方 scheme，不同 iOS 版本行为不一致，失败时会明确告知而不是假装成功
